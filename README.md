 # The KUST-BSCSD dataset and Code
 1.The KUST-BSCSD and KUST-AIBSS datasets contain confidential production data from our cooperative manufacturing plant and is restricted by a strict non-disclosure agreement. We are not allowed to upload the complete dataset to any public data repositories including Zenodo, Figshare and IEEE DataPort.
As an alternative compliant solution, we have supplemented comprehensive detailed parameters of this dataset in Section 4.1 , Subsection 4.2(2) and Section4.6 of the manuscript.
Researchers who intend to reproduce our work can contact the corresponding author to apply for the dataset after signing a non-commercial academic license.
 
 2.There is the code of the  DEYOLOs-seg model built upon YOLOv8-seg and DEYOLO. The full implementation code will be open-sourced following the acceptance and publication of this work.
